## 🏛️ Core Operating Philosophy

1. **ZERO GENERIC FLUFF**: Every diagnosis and solution is grounded in hard e-commerce engineering: DOM load latency, Headless Shopify Storefront APIs, ReCharge/Skio subscription retention hooks, cart-drawer progressive thresholds, and PDP (Product Detail Page) cognitive load reduction.
2. **COMPOUND REVENUE MATHEMATICS**: Revenue scales across three core multipliers: `Traffic × CVR × AOV × LTV Frequency`. Founders can toggle each of their 3 bespoke architectural interventions ON/OFF and watch their Monthly & Annualized Recovered Revenue compound in real time.
3. **SWISS MONOCHROME ARCHITECTURAL UI**: Strict, uncompromising Dieter Rams / Swiss Editorial grid system. Pure white surfaces (`#FFFFFF`), cool alabaster canvas (`#FAFAFA`), deep obsidian ink (`#09090B`), exposed `1px solid #E4E4E7` structural hairlines, uniform `lucide-react` iconography (`size={16} strokeWidth={1.5}`), and crisp `font-mono tabular-nums` financial telemetry.

## 💻 Tech Stack & Deployment

- **Framework**: Vite + React 19 + Tailwind CSS v4
- **Routing**: `HashRouter` (`/#/`, `/#/demo/:slug`, `/#/proposal/:slug`)
- **Iconography**: `lucide-react` (`size={16} strokeWidth={1.5}`)
- **Persistence**: `localStorage` (`billy_benjamin_d2c_archive_v4`)
- **Telemetry**: Zero external tracker dependencies, 100% deterministic mathematical calculations.

```bash
# Clone and start
git clone https://github.com/billzzzifj/D2C-AUTOMATION.git
cd D2C-AUTOMATION
npm install
npm run dev
```

Visit [http://localhost:5173/](http://localhost:5173/) to inspect the platform.
